# KING-BOB
King Bob is a smart Discord AI Bot that can be used through any model and its API Key with self developed crash handlers and rate reliefs through Logic.

## Developed on small scale but..
* It can keep any dead discord chat alive
* Its good to have a chaotic Minion in server.
* Its great for ppl for all age groups and can be asked for guidance.

# FEATURES OF BOB
* Available on whatever model you use just needs the API Keys while hosting.
* You can send messages as BOB in DM of a specific user in the server.
* Just simply say "BOB Warn @always_first11 for sneezing too loud and the user will receive
```
⚠️ Warning from ❄COLD❄II DRIVE WORLD CLUB

You have received an official warning.

Reason: for sneezing too loud

Please follow the server rules. Repeated violations may result in further action.
```
## Variables and their names : 
1. API_KEY          --------------> API Key number 1
2. API_KEY_4        --------------> API Key number 2
3. API_KEY_3        --------------> API Key number 3
4. API_KEY_2        --------------> API Key number 4
5. API_KEY_1        --------------> API Key number 5
6. OWNER_ID         --------------> Discord ID you get from discord (Steps mentioned Below)

### OWNER_ID
Its basic id that you get from discord which is required for Owner based commands
